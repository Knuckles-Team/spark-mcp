# CONN-SPARK-MCP-SPARK4 — Requirements

Governing spec: [spec.md](spec.md).

Each row is one requirement. The generator sets each row's state in `status.json`.

| ID | Requirement | Acceptance |
|---|---|---|
| `CONN-SPARK-MCP-SPARK4-R001` | **Spark Connect read queries.** `query_table`, `count_rows`, `summarize_table` and `explain_query` in `spark_mcp/api/api_client_spark.py` must run through one Spark Connect session. A failed query must raise a typed job failure. An unreachable server must raise a typed unreachable error. Caller chain: an MCP tool of `spark_mcp/mcp_server.py` calls `query_table` (`spark_mcp/api/api_client_spark.py:212`), `count_rows`, `summarize_table` or `explain_query`, which share one Spark Connect session. Shape: the Spark Connect session wrapper in `spark_mcp/api/api_client_spark.py`; failures raise the typed job-failure and unreachable errors of `spark_mcp/models.py`. Proving test: `tests/test_api_client.py::test_sql_returns_rows_and_columns`. | `tests/test_api_client.py`: rows and columns return, and the two typed errors raise. |
| `CONN-SPARK-MCP-SPARK4-R002` | **Catalog reads.** `list_catalogs`, `list_databases`, `list_tables`, `list_columns` and `list_functions` must read the Spark 4 catalog. Each tool carries the read-only hint. Caller chain: an MCP tool of `spark_mcp/mcp_server.py` calls `list_catalogs` (`spark_mcp/api/api_client_spark.py:310`), `list_databases`, `list_tables`, `list_columns` or `list_functions`. Shape: the catalog reads in `spark_mcp/api/api_client_spark.py` with the read-only tool hint. Proving test (planned): `tests/test_catalog_reads.py::test_each_catalog_read_carries_the_read_only_hint`. Proving test (planned): `tests/test_catalog_reads.py::test_each_catalog_read_carries_the_read_only_hint`. | `tests/test_api_client.py` asserts each catalog read and its hint. |
| `CONN-SPARK-MCP-SPARK4-R003` | **Monitoring REST reads.** `spark_mcp/api/api_client_rest.py` must serve one tool per monitoring REST read: version, applications, jobs, stages, executors and SQL executions. A tool may target the driver or the history server. Caller chain: an MCP tool of `spark_mcp/mcp_server.py` calls one method of `spark_mcp/api/api_client_rest.py`, which sends the monitoring REST request to the driver or the history server. Shape: one tool per monitoring read in `spark_mcp/api/api_client_rest.py`, chosen by the `server` argument. Proving test: `tests/test_rest_operations.py::test_history_server_is_selected_by_server`. | `tests/test_rest_operations.py` asserts one tool per read and the server choice. |
| `CONN-SPARK-MCP-SPARK4-R004` | **Governed transform submit.** A SQL transform submit must refuse while transforms are disabled. An enabled submit must record its run. Cancel must stop all runs or the runs of one tag. Caller chain: an MCP tool calls `submit_transform` (`spark_mcp/api/api_client_spark.py:475`), which calls `_require_transforms_enabled` (`spark_mcp/api/api_client_spark.py:436`); `cancel` (`spark_mcp/api/api_client_spark.py:413`) stops runs. Shape: `submit_transform`, `cancel` and the run record in `spark_mcp/api/api_client_spark.py`. Proving test: `tests/test_api_client.py::test_submit_transform_refuses_when_disabled`. | `tests/test_api_client.py`: the disabled refusal, the recorded run and both cancel forms. |
| `CONN-SPARK-MCP-SPARK4-R005` | **Source-build dependency.** `pyproject.toml` must name `pyspark-client` in `[tool.pipelines] allow-source-build`, per PIPE-RELEASE-R010. No other dependency may build from source. Caller chain: the wheel-readiness gate (`dependency-readiness`) reads `[tool.pipelines] allow-source-build` in `pyproject.toml` before every release. Shape: the list `allow-source-build = ["pyspark-client"]` in `pyproject.toml`; no other dependency builds from source. Proving test (planned): `tests/test_source_build_allowlist.py::test_only_pyspark_client_builds_from_source`. Proving test (planned): `tests/test_source_build_allowlist.py::test_only_pyspark_client_builds_from_source`. | The wheel-readiness receipt lists exactly `pyspark-client`. |
